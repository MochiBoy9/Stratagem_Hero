# Stratagem Hero
A fake, web-based version of the Stratagem Hero game you can find on the Super Destroyers. Vibecoded using Claude + Gemini (im on free trials LMAOO)

## Tutorial
For those who are new to Stratagem Hero, it's a game on Helldivers 2 that comes bundled with the Super Citizen Edition bundle. Players must survive waves of stratagem inputs, and make sure they can finish each wave under the time limit or else they lose. Every 5th wave introduces a longer sequence of inputs, and the time runs out faster for each successful wave.

Players can use WASD and Arrow Keys on they keyboard, mobile players can tap the arrows at the bottom, and controller is still being developed.

## Modes
* **Stratagem Hero** — the wave mode above. An **Emergency Deploy** call can interrupt a run from wave 2: read the radio call and pick the right stratagem for +5s on the wave clock. The clock doesn't stop while you decide.
* **Emergency Deploy** — the same call-outs as a mode of their own.
* **Flow Regulation** — the E-710 pipe puzzle. Slide the vertical rows so the line runs from the marked intake to the marked outlet.
* **Signal Descrambler** — the Automaton interception. The pattern is column-for-column with the array; only the vertical position is scrambled.
* **Landing Zone Confirmation** — Command calls a grid reference, you walk the cursor onto it and confirm.
